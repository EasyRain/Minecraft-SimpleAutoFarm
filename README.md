# 简易自动农场 Simple Auto Farm

一个面向 Minecraft 的小型 MOD，添加全自动的种植/收获/矿石机器与配套的能量系统：

- **简易自动农场**：放入种子即可自动「种植 → 生长 → 收获」，产物进入下方输出槽。
- **简易自动矿石农场**：放入矿石/粗矿样品即可自动「复制」；放入水晶母岩则产出对应晶簇的掉落。
- **简易水源方块**：玻璃外壳内含一格水，像原版水一样滋润 9×9 农田，持有无限水并向六个面主动出水。
- **简易发电机**：燃烧原版燃料（煤/木板等）产生 FE，自动向相邻机器输电。
- **简易发电机 Pro**：10 倍产能的进阶发电机，以熔岩为燃料，支持流体注入。
- **升级系统**：速度 / 效率 / 速度效率（两条线合并）/ 产量 / 时运五类升级（各 T1~T4），以及无合成表的**创造升级**。

本仓库同时维护两个版本（各自为独立的 Gradle 项目，互不干扰）：

## 功能特性

### 简易自动农场

- **单方块全自动**：9 个输入槽（每格 1 个样品，作为标记不消耗）+ 27 个输出槽（只能取出）。
- **只收植物**：原版作物（小麦/甜菜/胡萝卜/土豆等）、下界疣、树苗、竹子、甘蔗、蘑菇、花、灌木、
  海带、发光浆果、垂滴叶、瓶子草、发光地衣，以及第三方 MOD 的植物（神秘农业作物等）。
  **水晶母岩等非植物方块请改用矿石农场**。
- **FE 能源驱动**：默认每槽每 tick 耗 100 FE；能量足够才生长，能量不足自动暂停。
- **整体进度条**：所有已种作物共享一个生长进度，成熟时一次性收获全部。
- **自动弹出**：可选，自动把产物推到相邻容器。
- **破坏保留内容**：挖掘机器时物品与能量随本体一起掉落（写进 `block_entity_data`），重新放置后还原。

### 简易自动矿石农场

- **样品复制**：9 个输入槽 + 27 个输出槽；放入带 `c:ores` / `c:raw_materials` 标签的物品（矿石、粗矿），
  每完成一批产出**同样的物品**（识别口径与 useless_mod 的矿石生成器一致，纯标签判定，不查名字/配方）。
- **水晶母岩**：放入紫水晶母岩 / AE2 赛特斯石英母岩 / GeOre 等 `budding` 方块时，改为产出该晶簇的掉落
  （紫水晶母岩 → 紫水晶碎片），数量按各 MOD 自己晶簇的定义（赛特斯/过载/莱卓罗 ×4、恩特罗 ×1）。
- **同套机制**：FE 驱动、整体进度、自动弹出、AE2 直输、破坏保留内容，升级与农场通用。

### 简易水源方块

- **玻璃外壳 + 一格水**：外观是玻璃框里嵌一块流动的水；内部持有 **int 上限的水且永不消耗**。
- **滋润农田**：像原版水一样，把周围 **9×9（±4 格、同层与下一层）** 的农田保持在满水分（含继承了原版农田类的第三方农田）。
- **主动出水**：每 tick 向**六个面**的流体容器/机器输出水（对方能接多少接多少），也能接管道/水泵抽取。
- **右键交互**：手持水桶、玻璃瓶或任何流体容器右击即可灌满（倒进去的流体会被直接吞掉），带水花与音效。
- **配方**：8 个玻璃 + 1 个水桶。

### 发电机

- **简易发电机**：烧任意原版燃料产电，自动向四周相邻机器输电；带 2 个升级槽。
- **简易发电机 Pro**：
  - 基础产能 / 缓存 / 输出 / 推送均为普通发电机的 **10 倍**。
  - 以**熔岩**为燃料：右键用熔岩桶或其它 MOD 的流体容器注入；燃料槽里的物品燃料也会自动换算成熔岩。
  - 熔岩按量消耗（1 mB = 1 秒），GUI 带熔岩条与火焰图标。

### 升级系统

- **速度升级**（T1~T4）：缩短农场每轮时间、提升发电机产能/输出/推送（同时增加燃料消耗）。
- **效率升级**（T1~T4）：降低农场能耗、提高能量输入/缓存、降低发电机燃料消耗。
- **速度效率升级**（T1~T4）：把上面两条线**合成一个插件**（同级效果完全一致），三个升级槽就能同时装下它 + 产量 + 时运。
- **产量升级**（T1~T4）：提高农场产物数量（×4 / ×16 / ×64 / ×256）、提升输出槽堆叠上限。
- **时运升级**（T1~T4）：**随机增产**——每件产物等概率 roll 出 1×~（1+级别）×（T1 是 1×/2× 各 50%，
  T2 是 1×/2×/3× 各 33%…），与产量升级叠乘；能耗 +25%/级，堆叠上限 64×(级别+1)。
- **创造升级**（无合成表，创造物品栏获取）：忽略其它升级，农场 1 秒一轮、产物与堆叠为 `Integer.MAX_VALUE`、
  无需能量；发电机无需燃料、产能/缓存/输出/推送全为 `Integer.MAX_VALUE`。

## 构建

各自目录下运行（构建产物会同时复制到工作区根目录与测试客户端 `mods` 目录）：

```bat
:: 1.21.1 版（需要 JDK 21）
cd SimpleAutoFarm-1.21.1
gradlew.bat build

:: 26.1.2 版（需要 JDK 25，Gradle 会自动下载 toolchain）
cd ..\SimpleAutoFarm-26.1.2
gradlew.bat build
```

开发环境运行：`gradlew.bat runClient` / `runServer`。

## 安装

1. 安装对应版本的 NeoForge。
2. 将对应版本的 `simpleautofarm-<MOD 版本>-<MC 版本>.jar` 放入 `mods` 文件夹。
